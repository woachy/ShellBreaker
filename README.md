# 懒人解压😋 (ShellBreaker)

Windows 批量智能解压工具 —— 专治反复嵌套压缩、改后缀伪装与加密资源。

---

## 这是什么

在下载某些网络资源时，经常会遇到以下令人头疼的打包方式：
- **反复套娃**：解压开是一个压缩包，再解压还是一个压缩包（甚至套了三四层）；
- **改后缀伪装**：为了防屏蔽，将压缩包后缀故意改成 `.mp4`、`.jpg`、`.png` 或 `.pdf`；
- **加密保护**：每个包都有密码，一次下载几十个，手动一遍遍输密码费时费力。

**懒人解压**就是为这种场景打造的批量工具：把文件或文件夹往里一拖，软件自动识别伪装、逐层解开套娃、自动匹配密码库，拖进去等结果即可。

---

## 核心特性

- 📦 **批量与目录递归**：支持多选文件或直接拖入整个文件夹，自动深度递归扫描所有目标包。
- 🧅 **多层嵌套彻底剥离**：无论套了多少层压缩包，自动循环递归解压，最终产物直接平铺在外包文件夹内，绝不残留多余的临时空壳。
- 🎭 **伪装后缀智能识别**：自动探测被伪装为视频（`.mp4`）、图片（`.jpg`/`.png`）、文档（`.pdf`）等格式的压缩包并还原解压。
- 🔑 **密码自学习系统**：解压时自动轮询密码库；遇到新密码仅需输入一次，验证成功后自动记住，下次同类资源直接秒解。
- ⚡ **双内核与并发加速**：自动检测并支持 Bandizip (`bz.exe`) 与 WinRAR 命令行静默调用，支持多任务并发解压。
- 🖥️ **现代便捷交互**：
  - **双击直达**：双击已完成任务，直接在资源管理器中打开并高亮定位目标文件夹；
  - **右键菜单**：支持快速复制路径、打开目录、单项重新解压与列表清理；
  - **全局投放**：支持全窗口拖拽投放，也提供点击选择文件/目录按钮；
  - **实时看板**：带进度统计栏，支持一键清空已完成任务。

## 快速上手

### 方式一：下载即用（推荐）
直接从仓库的 **[Releases](../../releases)** 页面下载已打包好的 `懒人解压.exe`，解压到任意目录双击即可运行。

### 方式二：源码运行
1. 确保已安装 Python 3.12+。
2. 安装依赖：
   ```bash
   pip install PySide6
   ```
3. 运行程序：
   ```bash
   python main.py
   ```

> **注意**：运行前需确保电脑已安装 **Bandizip** 或 **WinRAR**（标准安装路径软件会自动识别；若安装在特殊位置，可在界面的「全局设置」中手动指定）。

## 常见问题

**Q：解压加密包时会弹出解压软件的窗口吗？**  
A：不会。软件已完全静默接管解压引擎，无感测试密码，绝不弹窗打扰。

**Q：拖入文件后没有开始解压？**  
A：请确认电脑已安装 Bandizip 或 WinRAR。若路径较为特殊，请点击界面下方的「⚙️ 全局设置」，手动浏览选中 `bz.exe` 或 `WinRAR.exe`。

**Q：杀毒软件提示报毒拦截？**  
A：本程序为 Python PyInstaller 单文件打包的开源工具，不含任何恶意行为，误报添加信任即可。
