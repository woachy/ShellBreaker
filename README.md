# 懒人解压😋 (ShellBreaker)

一个面向 Windows 的"懒人向"批量解压工具：把文件或文件夹拖进去，剩下的交给它。

## 功能特性

- **拖拽即用**：支持拖入单个文件或整个文件夹；拖入文件夹会自动递归扫描，批量解压
- **多引擎支持**：自动发现 Bandizip（bz.exe）与 WinRAR，也可在全局设置中手动指定路径
- **密码自学习**：优先自动尝试密码库 → 全部失败才弹窗询问 → 输入正确后自动记入密码库，下次免输入
- **沙箱隔离**：解压过程在专属临时沙箱中进行，伪装成其他格式的压缩包（如 `.mp4` 改名的 `.zip`）也能安全处理
- **嵌套压缩包**：自动递归解压多层嵌套的压缩包
- **并发解压**：可配置最大并发任务数
- **输出灵活**：默认解压到源文件同级目录，也可指定自定义输出路径
- **大小过滤**：跳过过小的文件，避免无意义解压

## 技术栈

- Python 3.12+
- PySide6（Qt for Python）
- PyInstaller（打包）
- 底层依赖 Bandizip 或 WinRAR 命令行

## 项目结构

```text
main.py                程序入口（日志、异常兜底、加载样式与图标）
ui/                    界面层：主窗口、密码管理、全局设置
core/                  核心逻辑：任务队列、沙箱隔离、解压引擎
data/                  数据层：配置与密码库持久化（仅本地文件）
assets/                样式表（QSS）与应用图标
懒人解压.spec          PyInstaller 打包配置
rule.md                项目开发规范（"铁律"）
```

## 快速开始（源码运行）

1. 安装 Python 3.12 或更高版本
2. 安装界面依赖：

   ```bash
   pip install PySide6
   ```

3. 安装任一解压引擎：Bandizip 或 WinRAR（建议安装到默认位置，程序会自动发现）
4. 运行：

   ```bash
   python main.py
   ```

## 打包为独立 exe

```bash
python -m PyInstaller --noconfirm --clean 懒人解压.spec
```

打包产物为 `dist/懒人解压.exe`（单文件，无需安装 Python）。

> 注意：PyInstaller 打包的 exe 偶尔会被杀毒软件误报，添加到信任列表即可，这是已知的常见现象。

## 使用说明

### 主窗口

- 把**文件**或**文件夹**拖入顶部的放置区即可开始解压
- 下方任务看板实时显示每个任务的进度与状态：

| 状态 | 颜色 |
| --- | --- |
| 成功 | 绿色 |
| 失败 | 红色 |
| 正在提取 / 验证密码 | 蓝色 / 琥珀色 |
| 排队中 / 已跳过 | 灰色 / 琥珀色 |

### 密码管理

- 解压加密包时，程序先自动尝试密码库中的密码；全部失败后会弹出输入框
- 手动输入的密码会自动入库，后续同类压缩包直接命中
- 可在「密码管理」中查看、添加、删除密码

### 全局设置

- **解压引擎路径**：不指定则自动扫描；指定后优先使用
- **默认执行引擎**：Bandizip 或 WinRAR 优先
- **默认输出路径**：源文件同级目录，或自定义目录
- **性能与过滤**：最大并发数、递归扫描层数、最小文件大小过滤

## 数据与隐私

- `data/passwords.json`：密码库（**明文**保存，仅存于本机）
- `data/config.json`：设置（可能包含本地路径）
- `logs/`：运行日志（可能包含文件路径）

以上均为本地文件，**不会**进入版本库（已在 `.gitignore` 中排除）。请勿把这三个目录/文件分享给他人。仓库内提供了 `data/config.example.json` 作为配置模板。

## 常见问题

**问：拖入压缩包没反应？**
答：确认已安装 Bandizip 或 WinRAR；若安装位置特殊，请在「全局设置」中手动指定引擎路径。

**问：exe 被杀毒软件拦截？**
答：PyInstaller 单文件程序的常见误报，添加信任即可。

**问：忘记密码怎么办？**
答：程序不提供找回密码功能；密码由用户自己保管。
