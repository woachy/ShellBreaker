# 懒人解压😋 (ShellBreaker)

> 破壳器：一键击穿伪装外壳，批量提取隐藏的压缩包。

## 这是什么

总有一些压缩包会被刻意伪装成普通文件：`.zip` 改名为 `.mp4`、`.rar` 改名为 `.jpg`、`.7z` 改名为 `.pdf`……它们散落在嵌套多层的文件夹里，有些还设置了密码。手动一个一个找出来再解压，既麻烦又容易漏。

**懒人解压**就是为这种场景设计的：把文件或文件夹拖进去，程序自动扫描、识别伪装、批量解压，全程零思考、零操作。

## 功能特性

- **伪装识别**：不只相信后缀名，伪装成图片 / 视频 / 文档的压缩包也能被识别，并在沙箱中还原为 `.zip` 后解压
- **递归深挖**：拖入文件夹后，按设定深度遍历所有子目录，把隐藏的压缩包一一揪出
- **沙箱隔离**：每个任务在独立临时沙箱中执行，防覆盖、防污染，伪装包也不会误伤原文件
- **密码自学习**：先自动尝试密码库 → 全部失败才弹窗询问 → 正确密码自动入库，下次免输入
- **懒人操作**：一次拖拽 → 自动扫描 → 批量入队 → 多线程解压 → 看板实时反馈
- **多引擎支持**：自动发现 Bandizip / WinRAR，可手动指定路径与切换偏好
- **输出灵活**：解压到源文件同级目录或自定义路径；可过滤过小文件

## 技术栈

- Python 3.12+
- PySide6（Qt for Python）
- 底层依赖 Bandizip 或 WinRAR 命令行
- PyInstaller（发布打包，配置见 `懒人解压.spec`）

## 项目结构

```text
main.py            程序入口（日志、异常兜底、加载样式与图标）
ui/                界面层：主窗口、密码管理、全局设置
core/              核心逻辑：任务队列、沙箱隔离、解压引擎
data/              数据层：配置与密码库持久化（仅本地文件）
assets/            样式表（QSS）与应用图标
懒人解压.spec      PyInstaller 打包配置
rule.md            项目开发规范（"铁律"）
```

## 快速开始

1. 安装 Python 3.12 或更高版本
2. 安装界面依赖：

   ```bash
   pip install PySide6
   ```

3. 安装任一解压引擎：Bandizip 或 WinRAR（建议安装到默认位置，程序会自动发现）
4. 运行：

   ```bash
   python main.py
   ```

已打包好的版本可从仓库的 **Releases** 页面下载，解压即用。

## 使用说明

### 主窗口

- 把**文件**或**文件夹**拖入顶部放置区即可开始解压
- 下方任务看板实时显示每个任务的进度与状态：

| 状态 | 颜色 |
| --- | --- |
| 成功 | 绿色 |
| 失败 | 红色 |
| 正在提取 / 验证密码 | 蓝色 / 琥珀色 |
| 排队中 / 已跳过 | 灰色 / 琥珀色 |

### 密码管理

- 解压加密包时，程序先自动尝试密码库中的密码；全部失败后会弹出输入框
- 手动输入的密码会自动入库，后续同类压缩包直接命中
- 可在「密码管理」中查看、添加、删除密码

### 全局设置

- **解压引擎路径**：不指定则自动扫描；指定后优先使用
- **默认执行引擎**：Bandizip 或 WinRAR 优先
- **默认输出路径**：源文件同级目录，或自定义目录
- **性能与过滤**：最大并发数、递归扫描层数、最小文件大小过滤

## 数据与隐私

- `data/passwords.json`：密码库（**明文**保存，仅存于本机）
- `data/config.json`：设置（可能包含本地路径）
- `logs/`：运行日志（可能包含文件路径）

以上均为本地文件，**不会**进入版本库（已在 `.gitignore` 中排除）。请勿把这些文件分享给他人。仓库内提供了 `data/config.example.json` 作为配置模板。

## 常见问题

**问：拖入压缩包没反应？**
答：确认已安装 Bandizip 或 WinRAR；若安装位置特殊，请在「全局设置」中手动指定引擎路径。

**问：从 Releases 下载的 exe 被杀毒软件拦截？**
答：PyInstaller 单文件程序的常见误报，添加信任即可。

**问：忘记密码怎么办？**
答：程序不提供找回密码功能；密码由用户自己保管。
